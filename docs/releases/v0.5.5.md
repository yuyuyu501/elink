# Elink 0.5.5 Cross-platform Preview

更新 Android 界面并补齐手机向桌面通告在线身份的路径。Windows、Linux 和 Android 请一起更新。

- Android 主页改为设备、设置、关于三个页面，统一桌面端的浅色背景、蓝色强调色和设备卡片样式。
- 设备页区分在线与已保存的离线设备，显示本机身份、设备平台和占用状态；Android 标注“仅控制端”，连接按钮禁用。
- 设置页提供画质和默认触控方式；关于页提供版本、更新页面、项目主页和诊断日志导出。
- 手机刷新桌面设备时，额外通过现有 HTTPS 连接通告自身身份，补充 UDP 广播；Windows、Linux 收到后将手机加入在线列表。
- 保留设备身份去重和 35 秒在线过期；Android 发现监听失败会重试，发现和连接错误保留阶段、消息及异常栈。
- 改善小屏和横屏页面布局，画质对话框支持滚动。

验证：Python 全套测试；Android 单元测试和 lint；Windows 与 Deepin Linux 实机接收 Android 格式的 HTTPS 通告，验证设备可见、重复合并和不可连接。Android 自动测试覆盖首页导航、小屏/横屏布局及真实异常的文件日志和导出报告。

实机通告由测试电脑发送，未连接真实手机自动测试。手机 Wi-Fi 上的最终发现效果和视觉效果仍需安装新版 APK 手动验收；本次不宣称已经定位手机 UDP 单向失败的具体过滤位置。Android 在系统挂起或终止后台应用后不保证持续在线。

Windows 提供完整便携 ZIP 和离线 Setup.exe；Linux 提供 Deepin 25 x64 / X11 验证的 .deb；Android 提供 arm64 APK。Windows Preview 尚无受信任的发布签名。Android 的“查看更新”打开 Releases 页面，不包含自动安装更新功能。不安装驱动。
