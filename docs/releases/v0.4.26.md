# Elink 0.4.26 Windows Preview

改善短时大帧的发送等待，新增可选空间超分，并减少桌面缩放和颜色转换占用的 CPU 时间。

- 发送采用平均预算与短时峰值双约束，容忍有限突发；音频和 RTCP 不再等待视频限速锁，重传仍计入预算。保持用户目标码率，只有持续丢包或 RTT 增长才降低有效编码预算，恢复后逐步回到用户设置。
- 画质新增“原生 100%”“FSR 1 · 75%”“FSR 1 · 66.7%”。默认原生；66.7% 以较低宽、高传输，例如 1080p 输出传输 720p，再在控制端 GPU 上执行 EASU + RCAS。需要两端更新，选择超分会启用 GPU 显示。
- 被控端尝试 D3D11 采集、GPU 缩放/转换后回读 NV12，验证颜色矩阵/范围；无法可靠校准或采集失败时提示并回退兼容采集。保留原生分辨率与 CPU 显示选项。
- 性能报告新增大帧、发送等待、反馈、恢复请求和接收间隔事件，以及异步 FSR GPU 计时；简洁状态栏不增加目标码率等项目。
- 冻结 EXE 自检新增两档超分的实际窗口显示、串流回退，以及三档 GPU 采集经编码/解码的颜色检查。

缩小后的像素数更少，但固定目标 Mbps 不会自动下降；小字、细线和色度信息可能损失。这里使用 FSR 1 空间超分，没有 FSR 3.1 运动重建或补帧。系统分辨率、DPI 和刷新率保持不变。

验证：RTX 4070 SUPER、本机分进程、20 Mbps、NVENC / D3D11VA / GPU 显示，每组合预热 2 秒、测量 6 秒。原生 28 个允许组合均达到目标帧率的 95%；66.7% 超分 33 个允许组合中 30 个达到，1080p90 约 88.9 FPS，FSR GPU 中位耗时约 0.10 ms。720p/900p/1080p 的超分 240 FPS 档在兼容采集回退后约为 155/155/141 FPS，仍未达标。校准回退频率与桌面内容有关，超分不保证更快。主屏约 75 Hz、1080p，1440p/4K 为放大输出；提交帧数可能包含重复帧，不是物理扫描数。

这不是完整 GPU 零拷贝，也不能硬性预留公网带宽。本机自动化与回环测试不替代两台电脑的游戏体验验收；用户反馈的 WAN 偶发卡顿仍需升级两端后复测。测量方法、代码依据和限制见随包 `docs/burst-and-upscaling.md`。

完整解压 `Elink-0.4.26-windows-x64.zip` 后运行 `Elink/Elink.exe`，保留配套目录。可在两端“关于 → 检测更新”并包含预览版本后升级。包为未签名 Windows 便携预览版，不安装驱动。
