# Elink 0.4.24 Windows Preview

修复 0.4.23 中 GPU 模式整个远控窗口仍黑屏、但 F8 菜单能够弹出的问题。

- GPU 显示改用 OpenGL 3.3 兼容配置。原 3.0 配置在本机可正确绘制内部纹理，但窗口合成输出全黑；最小程序对照与 Elink 实际屏幕检查均复现并验证了修正。
- 补齐实际屏幕输出检查，不再只依赖 Qt 内部截图或解码、绘制计数。覆盖状态栏、软件鼠标、全屏切换及软件 H.264 / D3D11VA 串流。
- 打包后的 EXE 必须额外通过 GPU 屏幕显示自检，发布流程检查该结果；GPU 真正不可用时仍可回退 CPU 显示。

两端可通过“关于 → 检测更新”升级，勾选“包括预览版本”。更新后重新连接，选择“GPU 纹理显示（实验）”验证。本机合成串流检查不等于双机游戏验收，实际游戏效果仍需手动测试。

下载 `Elink-0.4.24-windows-x64.zip`，完整解压后运行 `Elink/Elink.exe`，保留 `_internal` 等配套文件。本包为可直接运行的便携应用、未签名 Windows 预览版，不安装驱动。附带 `SHA256SUMS.txt` 和包含 GPU 自检结果的 `verification.json`。
