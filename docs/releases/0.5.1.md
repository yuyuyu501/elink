# Elink 0.5.1 Windows Preview

修复窗口化游戏鼠标进入标题栏／黑边的问题，并补齐桌面切换采集恢复和
会话异常诊断。本版本只更新 Windows；Linux、Android 继续使用 0.5.0。

- 游戏相对鼠标在窗口化、最大化和全屏下均约束到实际视频区域；桌面鼠标
  保持自由移出与悬停返回。光标状态短暂过期不会自行退出游戏模式。
- D3D11 遇到拒绝访问、桌面切换及读取阶段 ExternalError 时重建采集；
  等待期间保持视频时间轴，恢复后继续当前会话。
- 剪贴板原生写入移出网络线程；短暂心跳延迟增加有界恢复与独立 HTTPS
  探测，输入心跳缺失仍会释放已按住的按键。
- 两端异常自动写入滚动日志与 `logs/session-host-*.json`、
  `logs/session-controller-*.json`，性能报告包含失败阶段与异常堆栈。
- Windows 设置新增管理员重启入口，输入被拒绝时给出权限信息。UAC 需在
  被控电脑本地确认，本版本不支持控制 UAC 安全桌面。

已验证：CPU/GPU 原生鼠标边界、桌面返回、F8 和失焦释放；真实 RTC 下
模拟 16 秒采集拒绝仍保持会话；真实 D3D11 在重放已观察到的 ExternalError
后成功重建；模拟 6 秒无 pong 后恢复；双端异常日志与导出报告。

仍需验证：原先偶发心跳超时的最终根因尚未证实，此版包含阻塞路径修正、
恢复策略和诊断，不能保证已消除所有断连。管理员任务管理器实测未完成；
真实 UAC 全流程、实际游戏和已有 DXCam 后台线程的恢复仍需人工验收。
完整依据和限制见 `docs/session-input-recovery.md`。

下载 `Setup.exe` 为完整离线安装包；Windows ZIP 为免安装文件夹。
Preview 未商业签名，不安装驱动，不更改系统安全策略。
