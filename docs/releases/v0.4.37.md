# Elink 0.4.37 Windows Preview

超分算法默认只列出 FSR 1，后台确认 NVIDIA RTX 视频超分有效后才显示 RTX Video Super Resolution；远控错误提示增加关闭按钮，并默认 3 秒后隐藏。

- 启动与打开画质设置时异步检查本机驱动实际输出，检测期间不阻塞设置界面。默认选择 FSR；驱动可用后仍可手动选择 RTX。旧设置保存了 RTX、但当前不可用时自动使用 FSR。
- 检测使用合成亮度图比较超分开启/关闭的输出，不能只凭 NVIDIA 显卡型号或接口调用成功判定可用。已有正在工作的 RTX 处理器时复用其验证结果，避免多个处理器竞争。开启驱动视频超分后重新打开画质设置可再次检测，无需重新连接。
- RTX 实际渲染失败时继续 GPU 显示并安静回退 FSR，设置同步为 FSR，原因保留在文件日志和性能报告中，不再弹出截图中的长条回退报错。
- 其它远控错误提示可通过右侧关闭按钮关闭，默认显示 3 秒；同一错误不会反复重置计时或在关闭后立即重弹。提示层处理本机点击，不会同时点击远端；鼠标返回画面仍可恢复控制。错误文本仍写入日志。

验证包括设置恢复、异步检测、过期回调及窗口销毁、无效驱动接口、实际 Windows CPU/GPU 提示条显示/关闭/超时、真实驱动检测及 GPU FSR 回退。无效驱动的回退路径使用受控故障注入，未修改本机 NVIDIA 全局设置；实际驱动开启状态通过本机输出检测。打包检查重复运行这些原生界面检查。

文件日志：`%LOCALAPPDATA%\Elink\logs\elink.log`，也可从“关于 → 打开日志目录”进入。原先未复现的 D3D11 采集故障仍需发生时的被控端日志确认，本版不声明该未知故障已解决。

Windows Preview 未签名，不安装驱动；双机游戏体验仍需手动验收。
