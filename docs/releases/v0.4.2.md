# Elink 0.4.2 Windows Preview

本版本移除个人使用场景中的邀请、配对、批准和授权设备管理，改为自动发现同局域网或同 Tailscale 网络中的 Elink 主机。

## 使用

1. 两台 Windows 电脑安装并启动 Elink。
2. 主机打开“本机被控”。控制端在“远程连接”等待自动发现，选择机器后点击“开始串流”。同一台机器有局域网和 Tailscale 地址时只显示一项，并优先使用局域网路径。
3. 自动发现依赖 UDP 49201 和主机 TCP 49200 入站规则；发现失败时仍可手动填写主机地址。传输使用 TLS 证书指纹和 WebRTC DTLS/SRTP，主机只接受本机局域网或同 Tailscale 网段的来源地址。

## 变化

- 删除临时邀请、配对等待、主机批准、已授权设备列表、设备撤销和客户端授权文件。
- 主机返回稳定机器标识；控制端按机器标识合并多个网络路径，修复局域网 / Tailscale 重复设备显示。
- 增加 UDP 自动发现、局域网接口掩码判断、Tailscale 在线设备探测和 HTTPS 手动地址回退。
- 主机页面改为显示当前控制端和直接断开按钮；重新开启被控即可接受同网设备连接。

## 验证边界

本次发布前会运行自动测试、GitHub Windows CI、便携 EXE 音视频自测和更新替换自测。发布后由用户手动验收局域网发现、Tailscale 发现、直接连接、光标、键鼠、声音、手柄和游戏表现。个人使用降低了授权步骤，但网络内任何能访问 Elink 端口的设备都可以控制主机；请勿在不可信网络开放被控。
