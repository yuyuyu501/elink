# Elink 0.4.11 Windows Preview

本版本把码率设置明确为“目标码率”：链路容量足够时尽量维持用户设置值，拥塞时自动降低，恢复后逐步升回目标。

- 为 NVENC、AMF、QSV 和软件 H.264 增加 CBR `maxrate` 与低延迟 VBV 缓冲约束。
- 在编码器工作线程加入帧级 pacing，减少大帧突发造成的排队和丢包。
- 将设置项名称从“码率上限”改为“目标码率”。
- 在控制端和被控端对 WebRTC ICE UDP socket 尝试标记 AF41 DSCP，作为本机和支持 QoS 的网络设备的流量优先提示。

DSCP 是尽力而为的优先级标记，不提供跨 Tailscale、DERP 或公网的带宽保证。需要本机系统级策略时，可在控制端和被控端以管理员身份运行 `scripts/windows_qos.ps1 -Action Enable -ExecutablePath <Elink.exe路径>`；应用不会自动修改持久系统策略。自动化测试通过不代表双机游戏串流稳定，仍需用户手动验收。
