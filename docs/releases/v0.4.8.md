# Elink 0.4.8 Windows Preview

远控状态浮层收简为六行：连接方式、FPS、实时接收 Mbps、网络往返 RTT、帧间隔、视频丢包率。

- 接收速率由 Kbps 改为 Mbps，按 1000 换算并保留一位小数，例如 9300 Kbps 显示为 9.3 Mbps。
- 移除连接时长、码率上限、抖动、解码耗时和解码器显示，减少遮挡。码率上限仍可在画质设置调整。
- 保留路径探测、F10 显示 / 隐藏、数据过期和断线时的未知值提示。

RTT 表示网络往返时间，ms / frame 表示由显示 FPS 计算的帧间隔，不是两个可相加的端到端延迟分量。Mbps 表示当前实际接收速率，并非测速带宽上限。

下载 Elink-0.4.8-windows-x64.zip，完整解压后运行 Elink.exe，或通过“关于 → 检测更新”升级。此次浮层调整更新控制端即可生效。

发布流程验证自动测试、Windows CI、EXE 音视频自检及更新替换。双机功能的用户手动验收待完成，仍为未签名预览版。
