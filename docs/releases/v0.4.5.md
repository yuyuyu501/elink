# Elink 0.4.5 Windows Preview

画质设置集中到远控窗口；分辨率现在实际修改被控电脑的 Windows 显示设置，新增被控端系统缩放。

- 应用“设置”页仅保留本机监听端口与手柄后端，移除重复的画质表单。
- 打开“控制中心 → 画质与传输设置”，实时读取被控显示器的分辨率列表、当前值、缩放档位和推荐比例。
- 点击“应用并重新连接”才修改被控电脑，取消不改变配置；显示参数不会自动套用到另一台电脑。修改成功后，断开连接仍保留实际显示设置。
- 修改前检查支持范围，显卡拒绝或缩放失败时尝试恢复原值并报告错误。不支持缩放接口时禁用该项。
- 串流保持被控桌面的宽高比例，传输最高仍为 1080p；例如被控桌面可以设为 2560 × 1440，传输最高为 1920 × 1080。

需要两端升级至 0.4.5 才能修改实际显示设置。缩放接口依赖 Windows / 显卡支持，部分程序需重新打开以适应新缩放。本次不包含多显示器切换、虚拟显示器、HDR 或更高分辨率编码。

下载 **Elink-0.4.5-windows-x64.zip**，完整解压后运行 `Elink/Elink.exe`；已有应用可通过“关于 → 检测更新”升级。

验证覆盖动态列表、取消、实际会话请求与重连、非会话请求拒绝、原生调用边界和失败恢复、宽高比例、EXE 音视频及更新替换。原生设置写入在自动化中使用模拟后端；真实显示能力读取与双机手动变更验收分开记录。用户手动验收待完成，仍为未签名预览版。
