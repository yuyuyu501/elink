# Elink 0.4.25 Windows Preview

修复连接协商较慢时的启动心跳误超时，并改善高帧率串流的采集、发送和 GPU 绘制调度。

- 控制通道打开后才重新开始心跳响应预算，避免 ICE/DTLS 协商耗时提前消耗超时窗口；保留真正失联时的超时断开。
- 采集使用精确帧节奏、BGRA 输入及复用的颜色转换器；采集、编码和发送有界重叠，减少串行等待。GPU 显示由新帧通知驱动，减少轮询造成的帧损失。
- 改善 RTP 小批次发送节奏、低延迟编码缓冲及 NVENC 关键帧策略，保留用户设置与按需关键帧恢复；不修改被控端系统分辨率或刷新率。
- 增加覆盖 5 种分辨率 × 7 种帧率的可重复基准，记录真实编码、解码、绘制提交与阶段耗时，避免把设置值当作实际帧率。

验证：RTX 4070 SUPER、20 Mbps、NVENC / D3D11VA / GPU 显示，本机分进程回环。真实桌面 1080p90/120/144 的短时平均提交约为 89.1/119.4/141.4 FPS；28 个允许组合中 22 个达到目标的 95%。修复后的两套完整矩阵未出现启动心跳误断开。完整结果见随包 `docs/frame-rate-matrix.md`。

已知限制：真实桌面部分 165/240 档及 1440p144 仍未达标；CPU 桌面读取、缩放和颜色转换仍有开销，本版不是 GPU 零拷贝。当前 H.264 配置不允许 1440p165/240 和 4K90 及以上档位。测试主屏为 1080p/约 75 Hz，高帧率可能包含重复桌面画面，1440p/4K 桌面测试为放大；提交 FPS 不是屏幕实际扫描数，也不代表双机游戏已验收。

两端在“关于 → 检测更新”中勾选“包括预览版本”后升级，重新连接测试。也可下载 `Elink-0.4.25-windows-x64.zip`，完整解压后运行 `Elink/Elink.exe`，保留 `_internal` 等配套文件，无需另装 Python。

这是未签名 Windows 便携预览版，不是安装器，不安装驱动；附带 `SHA256SUMS.txt` 和 `verification.json`。自动检查与用户双机游戏手动验收分开记录。
