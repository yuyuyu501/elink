# Elink 0.4.12 Windows Preview

本版本修复远控会话的剪贴板和显示设置生命周期，并记录当前画质差异的原因。

- 控制端与被控端现在同步 Unicode 文本剪贴板，单次最多 64,000 个字符，抑制同步回环；图片、文件和富文本暂不包含在内。
- 远控期间修改的被控端分辨率和系统缩放，在正常退出、断开或会话超时后会尝试恢复进入会话前的状态。
- “应用并重新连接”会保留刚选择的显示设置，避免重连时被误恢复。
- 说明 Elink 当前全画面 H.264 路径与 UU 类远控的画质差异：当前画面没有额外锐化，清晰度主要受实际码率、全帧编码、H.264 4:2:0、缩放和内容感知策略影响。

显示设置恢复依赖被控端仍在运行且 Windows 接受恢复调用；应用崩溃、断电或系统拒绝恢复时无法保证还原。自动化测试通过不代表双机游戏串流稳定，仍需用户手动验收。
