# Elink 0.5.6 Cross-platform Preview

统一设备列表并更新 Windows、Android 界面。三端使用相同版本的协议与代码。

- Windows 主窗口固定为 920 × 680 逻辑像素，标题栏高 50 像素，侧边栏宽 204 像素；保留最小化与关闭按钮，调整颜色、圆角和悬停状态。
- Android 设备、设置、关于页面采用统一的浅色样式，底部导航铺满宽度。
- Android 设备页合并为一个紧凑列表，本机与其它设备统一排列，移除蓝色装饰条、在线徽章和独立搜索卡片；支持被控的设备在右侧显示连接按钮。
- 桌面端与 Android 移除手动刷新和添加设备入口，保留后台自动发现；网络诊断打开时自动更新。
- Android 仍为仅控制端，本机和其它仅控制端设备可显示但不能连接。
- 网页预览与原生布局同步，预览中的示例设备不代表实际在线设备。

Windows 提供完整便携 ZIP 和离线 Setup.exe；Linux 提供 x64 .deb；Android 提供 arm64 APK。

Windows Preview 未使用受信任发布签名，Android 延续原有 Preview 签名以支持覆盖更新。不安装驱动。本轮为界面更新，不宣称改善串流性能；手机、平板及双机实际使用效果由安装后手动验收。
