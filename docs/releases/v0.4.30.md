# Elink 0.4.30 Windows Preview

- 控制中心改为保持展开的面板，连续调整选项时不会自动收起；再次点击控制中心或按 F8 关闭。面板展开期间释放远端输入，收起后点击画面恢复控制。
- 鼠标设置增加 -5.0 至 +5.0 的灵敏度，步长 0.1，0.0 保持原速率，范围对应 0.5 至 2 倍。主控端调整桌面与游戏鼠标位移，保存设置，并保留低速移动的小数精度。
- 设置新增常规板块，支持当前用户开机自启，以及关闭主窗口时最小化到托盘。托盘提供恢复窗口和真正退出，最小化保留连接服务与现有会话。
- 自动更新绕过最小化到托盘设置，正常退出并交给更新助手。

验证包括鼠标位移与小数累积、控制中心连续操作和 F8、设置保存、独立测试注册表键的启动项读写、托盘隐藏/恢复/退出及活动会话保留、更新退出流程，以及完整测试和打包后的 EXE/GPU/采集/更新自检。

Windows x64 便携预览版，解压完整目录后运行 Elink.exe。应用及实验驱动未签名，不安装驱动。自动检查不代替双机游戏体验和所有 Windows/驱动组合的人工验收。
