# Elink 0.4.29 Windows Preview

画质设置改为“应用”，无需断开并重新连接。需要两端均更新至 0.4.29。

- 分辨率、目标帧率、码率、超分采样在当前视频轨道更新，保持 WebRTC 会话、输入、剪贴板与远控窗口。编码器参数变化时重新发送关键帧。
- 软件 H.264 / D3D11VA 在解码线程按关键帧切换；兼容显示 / GPU 显示、FSR / RTX 超分在原窗口切换。切换可能短暂停顿等待关键帧或重建采集资源。
- 音频通道在连接时预留，传输声音可直接开启或关闭。保留本机静音、统计和窗口状态。应用中防止重复提交，失败在原对话框提示，成功才保存偏好。旧被控端提示升级，不自动重连。
- 修复动态切换超分时 Qt GPU 计时对象引用失效窗口表面导致的崩溃；采用当前上下文中的 OpenGL elapsed query。原窗口复用一个渲染上下文。
- 关闭会话时等待预编码任务清理完成，避免传输已停止但预取任务仍在退出。

验证覆盖同一真实本机 WebRTC 会话的六次连续切换：720p / 1080p / 1440p、30 / 60 / 90 FPS、软解 / 硬解、CPU / GPU 显示、50% FSR / RTX 与原生采样、声音开关。检查会话和通道身份保持不变，并在真实桌面检查 GPU 输出像素。另验证 D3D11 桌面采集在 1080p60、720p90、1440p60、1080p120 间切换，时间戳递增且颜色正确。测试不修改 Windows 系统显示设置，不等同于双机网络、所有驱动或实际游戏验收。

完整解压 `Elink-0.4.29-windows-x64.zip`，运行 `Elink/Elink.exe`，保留配套目录。已安装版本可通过“关于 → 检测更新”，勾选包括预览版本后升级。未签名 Windows 便携预览版，不安装驱动。
