# Elink 0.4.23 Windows Preview

修复 GPU 纹理显示模式下，视频与状态栏、软件鼠标叠加绘制相互干扰，导致 OpenGL 错误及黑屏/回退的问题。

- 视频由独立 OpenGL 控件绘制，状态文字与软件鼠标使用透明叠加层，由 Qt 合成；叠加层不抢鼠标和键盘焦点。
- 移除父窗口绘制触发的视频重复重绘，避免空闲时持续刷新。
- GPU 绘制失败时同时移除视频层和叠加层，恢复 CPU 显示并显示错误提示。

本地 149 项自动测试通过。真实 Windows 桌面检查覆盖状态栏、软件鼠标显隐、全屏切换、控制菜单和颜色显示；本机合成 H.264/WebRTC 串流的软件解码、D3D11VA 解码和故障后的 CPU 回退均通过验证。双机实际游戏效果仍待用户验收，未将本机合成检查作为游戏性能保证。

建议两端更新后，在“控制中心 → 画质 → 显示方式”选择“GPU 纹理显示（实验）”，应用并重新连接。GPU 显示独立于解码器，可分别测试软件 H.264 和 D3D11VA；如仍有问题，可暂用“兼容显示（CPU）”并导出性能报告。

在“关于 → 检测更新”中升级，需包含预览版本；也可下载 `Elink-0.4.23-windows-x64.zip`，完整解压后运行 `Elink/Elink.exe`，保留 `_internal` 等配套文件。本包是可直接运行的便携应用，不是安装程序，仍为未签名 Windows 预览版，不安装驱动。附带 `SHA256SUMS.txt` 与 `verification.json`。
