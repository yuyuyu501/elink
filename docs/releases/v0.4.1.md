# Elink 0.4.1 Windows Preview

本次修复远控画面缺少鼠标，并新增“关于 / 检测更新”。Windows 10/11 x64，仍为预览版。

## 下载与升级

下载 **Elink-0.4.1-windows-x64.zip**，完整解压后运行 `Elink/Elink.exe`。这是完整便携应用，不是安装程序，不需要 Python；请保留整个文件夹。GitHub 的 Source code ZIP/TAR 是源码。

**0.4.0 用户需要手动下载本次更新，建议两端都更新。** 光标修复在被控端生效。配置和配对信息保存在独立用户目录，正常升级会继续使用。

从 0.4.1 开始，可在“关于 → 检测更新”查询后续版本。默认包括预览版；发现新版先询问，同意后下载、校验、退出、替换并重启。支持取消下载，旧应用目录保留，启动失败时尝试回退。无可达地址时仍需自行使用 Tailscale。

## 本次变化

- 主机合成系统光标，处理形状、热点、屏幕边缘及隐藏状态；桌面静止时移动鼠标也会更新，不在缓存画面留残影。游戏主动隐藏指针时不强制显示箭头。
- 新增版本信息、GitHub Releases 链接、检测更新、下载进度、取消和失败提示。更新后被控服务仍需手动开启。
- 默认开发流程改为本地修改 → 自动测试 → Git 同步 → Windows 打包 → GitHub Release。发布后由用户安装新版并手动验收。

## 验证与限制

发布脚本要求本地测试、对应提交的 GitHub Windows CI、便携 EXE 音视频自测以及真实 EXE 目录替换、重启和配置保留检查通过。随包 `verification.json` 记录具体结果，`SHA256SUMS.txt` 用于校验 ZIP。更新检查使用两份隔离的同版本 EXE 验证替换机制，不代表未来版本的数据迁移都已验证。

**本版本的用户手动功能验收尚待完成。** 游戏延迟、高帧率、跨网稳定性和实体手柄仍需实测；已有双机测试曾出现卡顿和丢包，本次未宣称修复这些性能问题。

应用未签名；不安装驱动或 Tailscale。ViGEm 兼容手柄模式需要主机已安装 ViGEmBus，ElinkPad 仍为实验驱动源码。不支持 Linux/Android、HDR/AV1、锁屏/UAC 或无人值守服务。
