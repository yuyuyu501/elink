# Elink 0.4.20 Windows Preview

本版本修复游戏中的智能鼠标错误，并减少主控端画面显示的额外开销。

- 修复 Raw Input 读取错误：智能鼠标不再访问不存在的 `mouse` 字段，游戏相对鼠标移动可以正常转发。
- 增加 Raw Input 相对移动、绝对移动和非鼠标事件的自动化回归测试。
- 当收到的画面尺寸与显示区域一致时直接复用 QImage，跳过无意义的逐帧缩放；需要缩放时仍使用平滑采样。

自动化测试通过（125 项）。真实 Tailscale 链路、不同显示分辨率、硬件编码器和游戏场景仍需安装后手动验收；当前 Windows 预览包未签名。
