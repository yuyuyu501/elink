# Elink 0.5.0 Cross-platform Preview

Windows、Linux 和 Android 共用现有 Elink 协议。无需 Sunshine/Moonlight
应用或新增服务器；跨网仍使用已有的可达地址或外部 Tailscale。

- 平台隔离：共享协议、会话和桌面界面；Windows/Linux 系统后端各自维护。
- Linux x64 同时提供控制端和被控端：X11 采集、XTest 键鼠、系统声音、
  剪贴板适配、SDL 手柄读取和 uinput 输出。Linux 更新选择 .deb。
- Android arm64 控制端：原生 WebRTC H.264/Opus、EGL 显示、设备发现、
  手动地址、触控/外接键鼠、基础手柄、画质应用、退出与错误日志。
- 修复 Linux 中文系统区域设置导致 PyAV 音频线程退出；空闲监听源保持
  音频时间轴。底层 WebRTC 收发错误写入滚动日志。

## 下载

- Windows：`Setup.exe` 为完整离线安装包；Windows ZIP 为免安装文件夹。
- Linux：`Elink-0.5.0-linux-x64.deb`，在登录后的普通用户桌面运行。
- Android：`Elink-0.5.0-android-arm64.apk`，Android 11 或更新的 arm64 设备。

Linux 构建基线为 Deepin 25 / glibc 2.38 / X11，不能保证更旧发行版兼容。
完整包包含 Python/Qt/媒体依赖，但不包含显卡驱动。uinput 权限、SDL2、
xclip 等系统能力按设备实际配置生效；程序不会安装驱动或更改设备权限。
Wayland 仅有实验源码实现，安装包不提供 Wayland 被控能力。

## 已验证与限制

Windows 自动回归，以及 Linux 实际 X11 桌面 CPU/OpenGL 像素、键盘与
坐标映射检查通过。Windows/Linux 双向 720p 音视频测试通过：Windows
NVENC 发往 Linux 的稳定段达到 60 FPS；Linux 软件编码反向约 54–56 FPS。
Linux 测试机缺少 NVIDIA 编解码运行库，未验证其 NVENC/CUDA 性能。

Android 构建、单元测试、lint 与签名检查自动完成；尚未做手机/平板运行
和桌面互通验收，由用户安装本 APK 后测试。设备声明的解码能力不等于
持续高帧率保证。虚拟手柄先提供基础按钮，未提供触控摇杆或震动反馈。
本轮不包含 Android 被控端、Android 自动更新、macOS/iOS。

Windows Preview 尚无商业代码签名；Android 使用持续保存的 Preview
签名身份。手动游戏验收与自动测试分开记录。
