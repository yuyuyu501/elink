# Elink 0.4.22 Windows Preview

新增可选 GPU 纹理显示和两端性能报告，方便比较显示路径并定位游戏串流卡顿。

- 控制中心 → 画质 → 显示方式，选择“GPU 纹理显示（实验）”后应用并重新连接。YUV 颜色转换与缩放交给显卡，绕过 BGR/QImage 的 CPU 显示转换；默认仍为“兼容显示（CPU）”，GPU 不可用时自动回退并提示。
- 支持 YUV420P/NV12、BT.601/709、有限/全范围与带行填充的纹理上传，修复兼容显示路径的 BT.709 转换偏色，并处理 Qt 顶层合成上下文造成的额外提交等待。
- 控制中心新增“导出性能报告…”，保存两端采集、编码、发送等待、解码和绘制阶段的 P50/P95/P99，以及本地队列丢帧计数。建议两端同时升级；旧主机仍可连接，但只导出控制端统计。
- 显示方式独立于解码器：软件 H.264 或 D3D11VA 都可选择 GPU 显示。简洁状态栏和目标码率、目标帧率策略保持不变。

本地 148 项自动测试通过，真实 Windows 合成画面的颜色、纹理步幅和全屏往返检查通过。在一次 1080p、120 帧合成测试中，准备至绘制提交 P95 从 CPU 路径约 11.18 ms 降至 GPU 路径约 1.27 ms。这是 CPU 调用/提交耗时，不是游戏 FPS、GPU 完成时间或双机输入到显示延迟。

GPU 路径仍上传 CPU 可访问的 YUV 平面，尚未实现 D3D11 解码表面直显或完整零拷贝；H.264/YUV420P 采样限制仍存在，不能保证消除所有文字毛糙。原生 D3D11 与后续网络优化尚未完成。两台电脑实际游戏表现待用户手动验收，应用仍为未签名 Windows 预览版。

下载 `Elink-0.4.22-windows-x64.zip`，完整解压后运行 `Elink/Elink.exe`，请保留旁边的 `_internal` 等文件。也可以从旧版“关于 → 检测更新”升级，需包含预览版本。附带 `SHA256SUMS.txt` 和 `verification.json`；打包流程验证真实 EXE 音视频、正常退出和便携目录更新替换，不安装驱动。
