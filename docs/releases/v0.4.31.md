# Elink 0.4.31 Windows Preview

- 修复游戏相对鼠标仍被捕获时，本机系统指针提前移出窗口、出现双光标的问题。增加 Windows 指针约束，范围对应实际视频区域并按原生客户区像素处理 DPI 与窗口移动；F8、失焦、模式切换及关闭时释放。
- 桌面鼠标越过实际视频边界时释放远端输入；黑边不再捕获鼠标或转发点击，避免窗口内外同时响应。
- 主界面报错提示增加关闭按钮，收起后仍保留诊断记录，后续错误可再次显示。
- 修复退出后被控端残留“控制中”且无法再次断开的会话清理问题。退出通知提前发送，并通过可靠输入通道和 HTTPS 独立传递；控制通道关闭立即结束会话，控制心跳中断超过 6 秒则超时清理。各项资源清理隔离异常并限制等待时间，确保恢复可连接状态；清理期间单独显示“正在断开”。

验证：296 项完整自动化测试通过，包括真实本机 TLS/WebRTC 的断线、心跳丢失、断开与再次连接，以及释放异常、超时和取消清理的回归测试。Windows 原生 CPU/GPU 播放器对照检查在禁用指针约束时均复现指针逃逸，启用后均通过边界约束、桌面越界、移动窗口、F8 与失焦释放检查。分数 DPI 与负坐标使用模拟原生坐标测试，未进行多显示器实机验收。

Windows x64 便携预览版，需解压完整目录后运行 Elink.exe；两端均更新以获得完整的退出通知与回收行为。应用未签名，不安装驱动。自动化和本机合成场景不代替双机游戏、多显示器或所有驱动组合的人工验收；游戏自身绘制在视频里的光标不属于系统指针约束的处理范围。
