# Elink 0.5.4 Cross-platform Preview

修复局域网设备发现与设备展示，Windows、Linux 和 Android 请一起更新。

- 多网卡分别绑定本地接口发送广播，支持有线和无线位于不同网段的情况。
- 发现请求携带自身在线信息，并对已发现设备使用单播刷新，修复本次实测中单向广播收不到导致的设备缺失。
- Android 也会主动通告和回应发现请求；设备列表显示在线的 Android，标注“仅控制端”，禁用连接操作。
- 同一设备多个地址合并，保留不同的同名设备；35 秒未收到在线信息的路由会过期。
- 增加发现失败日志，保留既有 HTTPS 地址连接与 Tailscale 探测。

验证：Windows 双网卡与 Deepin X99 实机连续两轮互相发现通过；桌面设备卡片、控制端专用角色、在线过期、UDP 往返和单播刷新有自动测试覆盖。Android APK 通过单元测试和 lint，手机实机发现仍需安装后手动验收。

这里的“所有在线设备”指运行 Elink 的设备。Android 暂不支持被控，系统挂起或结束后台应用后不保证持续显示在线；完全隔离客户端或阻断双向通信的网络仍无法自动发现。

Windows 提供完整便携 ZIP 和离线 Setup.exe；Linux 提供 Deepin 25 x64 验证的 .deb；Android 提供 arm64 APK。Windows Preview 尚无受信任的发布签名，Linux/Android 的真实游戏表现仍需手动验收。不安装驱动。
