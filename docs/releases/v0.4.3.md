# Elink 0.4.3 Windows Preview

打开 Elink 后本机自动进入可连接状态，移除“开启 / 关闭被控”操作。串流窗口新增左上角紧凑、半透明、纵向排列的实时统计，按 F10 显示或隐藏。

## 连接行为

- 主机启动后自动监听并参与发现；退出应用停止接入。无需额外点击开启被控，也不会设置开机启动或后台系统服务。
- 一台主机同时只接受一个控制端。连接协商和结束清理期间也拒绝第二台设备接入，返回占用提示。断开当前控制端后重新等待连接。
- “本机被控”页显示可连接 / 占用状态、当前控制端、断开按钮及连接设置。端口被占用时提示并自动重试；可更换端口后应用设置。正在被控时不能应用连接设置。

## 实时统计

依次显示连接时长、实际媒体路径、界面绘制 FPS、接收 Kbps、心跳 RTT、平均帧间隔、视频 RTP 丢包率、视频抖动、解码耗时、设定码率和解码器。数据约每秒刷新；没有数据或已过期时显示 `--`。

接收速率来自加密传输字节计数，包含音视频及控制开销；设定 Mbps 是码率上限，两者含义不同。`ms / frame` 为界面绘制帧间隔，并非端到端操作延迟；RTT 为往返时间。Tailscale 路径通过实际探测区分直连、DERP 和节点中继，尚未测得时显示“路径待测”。

## 下载与验证

下载 **Elink-0.4.3-windows-x64.zip**，完整解压后运行 `Elink/Elink.exe`，保留 `_internal` 等所有文件。0.4.1 / 0.4.2 可通过“关于 → 检测更新”升级，建议两端更新。更新后本机自动恢复可连接状态。

自动验证覆盖默认启动、端口失败重试、两控制端并发抢连、断开后重连、统计计数和单位、未知或过期数据，以及 Windows EXE 音视频和更新替换。验证报告中记录实际结果；用户安装后的手动功能验收待完成。此次不声称解决全部双机卡顿、高帧率或手柄兼容问题，应用仍是未签名预览版。
