# Elink 0.4.28 Windows Preview

修复 D3D11VA 硬件解码下浅灰背景发白、细线消失、暗部压黑及部分偏色的问题。相同视频使用软件 H.264 正常时，无需为保持画质而关闭硬件解码。

- PyAV 的硬件帧回读保留了像素，但遗漏颜色范围和色彩矩阵。Elink 在硬解出口从解码器的 H.264 码流信息补回缺失标记；已有的帧标记优先，不按分辨率猜测，不新增 RGB 拷贝或逐帧软件解码。
- 性能报告记录解码像素格式、色彩矩阵和亮度范围。默认码率、采样比例、帧率和超分选择保持原设置。
- 发布自检新增 16 组同码流软件 / D3D11VA 对比，覆盖 1080p / 1440p、BT.601 / BT.709、完整 / 有限范围和 YUV420P / NV12 输入，检查亮部、暗部、彩色区域及实际 GPU 窗口。

本机 RTX 4070 SUPER 实测：修复前完整范围 NV12 视频中，8 / 16 被转为黑色，245 / 250 被转为白色；修复后保留对应层次。16 组软件与硬解的采样 RGB 差异均为 0，距合成原图的最大通道误差为 3（H.264 有损编码）。这是已知合成颜色与真实硬解的验证，不等同于所有驱动、HDR 或两机游戏已经验收。

解压 `Elink-0.4.28-windows-x64.zip` 后运行 `Elink/Elink.exe`，保留配套目录与 DLL。已安装版本可通过「关于 → 检测更新」并包含预览版本升级。至少控制端需要更新；两端均更新便于后续诊断。未签名 Windows 便携预览版，不安装驱动。
