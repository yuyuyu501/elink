# Elink 0.4.27 Windows Preview

新增 RTX Video Super Resolution 和 50% 超分采样，以改善低分辨率串流在 FSR 1 下的文字边缘和细节表现。默认仍为原生 100%。

- 画质设置可独立选择 75%、66.7%、50% 采样，以及 RTX Video Super Resolution / FSR 1 算法。1080p + 50% 传输 960×540，再在控制端重建到 1080p。需要两端更新；不修改被控端系统分辨率、DPI 或刷新率。
- RTX 使用 NVIDIA 驱动的 D3D11 视频处理器，结果通过共享 GPU 纹理显示，正常播放没有超分结果的 CPU RGB 读回。未分发 NVIDIA SDK 或模型，也不安装驱动；现有解码平面仍有回读，并非完整零拷贝。
- 控制端须开启 NVIDIA App「系统 → 视频 → RTX 视频增强 → 超分辨率」。驱动接受调用但没有实际输出变化时，会提示并回退 FSR 1，避免把普通缩放误标为 RTX。HDR 无需开启。
- 性能报告增加 RTX 提交、异步 D3D11 计时和实际效果探针。冻结程序自检增加 RTX 原生窗口、真实串流、全屏重建及失败回退验证。

2026-10-20，本机 RTX 4070 SUPER、驱动 591.86、质量自动、NVENC / D3D11VA、20 Mbps / 90 FPS。FSR 与 RTX 使用同一份 540p 解码输入，三组静态合成图的 RTX PSNR / SSIM 均高于 FSR；桌面文字 SSIM 从 0.9446 提升至 0.9769，原生 1080p 为 0.9979。RTX 减少部分毛刺，但 540p 丢失的小字仍不能恢复到原生水平。

分进程 WebRTC 运动场景，分别预热 3 秒、测量 15 秒：原生约 89.80 FPS，50% FSR / RTX 均约 89.99 FPS，正式区间无解码错误或队列丢帧。RTX 绘制调用 P50 约 0.93 ms，FSR 约 0.59 ms。实际显示器约 75 Hz，这些是提交帧率，不是物理扫描帧率；不代表与游戏争用 GPU、WAN 或其它分辨率组合已经验收。测试条件与完整边界见随包 `docs/rtx-video.md`。

50% 会减少像素处理量，但固定目标 Mbps 不会自动下降。优先文字清晰度时仍建议原生，超分作为可选项。没有 FSR 3、时域重建或补帧；两机实际游戏体验等待安装后手动验收。

完整解压 `Elink-0.4.27-windows-x64.zip` 后运行 `Elink/Elink.exe`，保留配套目录及 DLL。两端也可通过「关于 → 检测更新」并包含预览版本升级。包为未签名 Windows 便携预览版，不安装驱动。
