# Elink 0.4.9 Windows Preview

远控状态浮层用主控端实际解码耗时（ms decode）替换由 FPS 推算的帧间隔（ms / frame），方便区分网络和解码性能。

仍保持六行：连接方式、FPS、接收 Mbps、网络往返 RTT、解码耗时、视频丢包率。不恢复连接时长或码率上限显示。

解码耗时来自最近一次解码调用，并非平均值，不包含后续 RGB 转换、绘制或屏幕显示；无近期视频或统计过期时显示未知。RTT 是往返时间，不能与解码耗时相加当作端到端延迟。

同时修复后台任务极快完成时的回调时序问题，避免“检测更新”按钮看似可用但再次点击无响应。

统计调整更新控制端即可。下载 Elink-0.4.9-windows-x64.zip 并完整解压运行 Elink.exe，或通过“关于 → 检测更新”升级。

发布流程验证自动测试、Windows CI、EXE 音视频自检与更新替换。用户双机手动验收待完成，仍为未签名预览版。
