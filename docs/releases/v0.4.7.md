# Elink 0.4.7 Windows Preview

远控窗口新增三种鼠标模式，替代“桌面鼠标 / 游戏相对鼠标”。两台电脑都应更新。

- 智能鼠标：默认选项，显示远端系统光标，根据被控端 Windows 光标是否隐藏自动切换绝对定位与游戏相对移动。
- 使用被控端鼠标：相对移动，显示被控端光标形状与位置，位置反馈随视频传输。
- 使用主控端鼠标：本机箭头即时移动，绝对定位；停止远端系统光标的视频叠加，避免持续双光标。等待远端模式确认后显示本机指针。
- 模式切换先释放按键，点击画面恢复控制；选择会保存并在重连后沿用。旧配置迁移为智能模式，旧被控端禁用不支持的选项。

智能模式按系统光标状态判断，并非游戏专项适配；检测存在心跳与网络延迟。主控端模式不复制远端光标形状，部分游戏不兼容，不能移除游戏自行绘制的光标；模式切换时缓冲中的旧视频帧可能短暂保留旧光标。

下载 Elink-0.4.7-windows-x64.zip 并完整解压运行 Elink.exe，或在“关于 → 检测更新”升级。

自动验证覆盖真实本机 WebRTC 模式传输与回传、合成开关、智能状态切换、旧主机兼容、配置迁移与重连、输入释放。打包流程另外验证 EXE 音视频及自动更新替换。双机桌面与具体游戏的用户手动验收待完成，仍为未签名预览版。
