# Elink 0.4.35 Windows Diagnostic Preview

本版补齐 D3D11 采集回退的诊断信息。此前报告只记录 `RuntimeError`，无法确定原始失败原因；本版不宣称修复此前的采集回退或帧率不足。

- 正常启动后写入 `%LOCALAPPDATA%\Elink\logs\elink.log`，记录版本、采集错误、后台任务和未处理异常。每文件约 2 MiB，最多保留 3 份轮转备份；自定义数据目录使用其 `logs` 子目录。
- “关于”页新增“打开日志目录”。文件日志保留完整异常堆栈；性能报告的两端 `failures` 带有界异常消息、堆栈、阶段和串流参数，`metadata` 标记应用及运行时版本。
- GPU 错误区分校准建图、同步帧、颜色校准、正式建图和读帧阶段；设置修改/恢复失败也会记录。导出时获取被控端报告失败的具体信息进入控制端报告。
- 保留 3 秒自动关闭的报告保存成功提示。诊断不主动记录桌面像素、键鼠或剪贴板内容，不捕获异常局部变量。

验证：受控全屏灰色画面在真实 D3D11 路径触发 `colored_blocks=0` 的颜色校准错误，报告和文件日志均保留 `calibration_colors` 阶段与堆栈，DXCam 回退后继续输出。当前正常桌面上 1280×720、120 FPS 参数的 GPU 采集启动成功。该对照只证明新诊断能够记录真实失败，不能证明用户此前那次回退由同一原因引起。另有日志轮转、无控制台写入、异常链、报告大小限制和真实本机 WebRTC 传回异常的自动化检查。

排查时请两端均更新，在原场景复现后于连接期间导出性能报告；必要时查看被控端的日志。旧被控端丢弃过的异常无法由控制端更新追溯恢复。

Windows x64 便携诊断预览版，解压完整目录运行 Elink.exe。未签名，不安装驱动；双机实际故障仍待复现定位及人工验收。
