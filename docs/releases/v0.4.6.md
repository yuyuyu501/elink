# Elink 0.4.6 Windows Preview

远控窗口改用单层标题栏，控制中心与窗口按钮放在同一行，移除原有“Windows 标题栏 + 应用工具栏”双层结构。

- 窗口模式标题栏高 40 个逻辑像素，支持拖动、双击最大化 / 还原、最小化和关闭。
- 释放远端输入后可拖动窗口边缘或四角调整大小。拖动和调整大小通过 Qt 的系统窗口操作接口执行。
- 全屏时视频使用整个窗口，控制输入被捕获后隐藏标题栏；按 F8 释放输入、显示标题栏并打开控制中心，点击画面重新控制。
- F11 退出全屏时恢复之前的普通 / 最大化状态。应用画质重连也保留最大化状态。
- 标题栏操作留在本机，不发送远端鼠标输入。视频鼠标坐标与统计位置适配新布局。

仍使用 PySide6 / Qt，没有新增 Electron 等前端框架。应用主窗口和画质对话框保留原系统窗口边框。本次不声称完全复刻 UU 窗口实现或 Windows 11 最大化按钮悬停分屏菜单。

下载 **Elink-0.4.6-windows-x64.zip** 并完整解压运行，或通过“关于 → 检测更新”升级。

验证覆盖窗口按钮、双击、全屏恢复、F8 可达性、边缘调整调用、坐标映射和本地输入隔离；另在实际 Windows 窗口后端检查单层边框和最大化工作区，打包时验证 EXE 音视频与更新替换。双机和不同 DPI / 多屏环境的用户手动验收待完成，应用仍为未签名预览版。
