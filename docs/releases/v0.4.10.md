# Elink 0.4.10 Windows Preview

本版本为接收端媒体链路建立分段性能基线，并移除 RGB 帧进入 Qt 时的第二次像素复制。

- 新增 `convert_ms` 和 `present_ms` 统计，分别表示 RGB 转换和 Qt 绘制调用耗时。
- `QImage` 直接包装当前 RGB numpy 缓冲并保留其所有权，减少一次内存复制。
- 文档明确 Python 控制平面与后续原生媒体 DLL 的路线；Windows 首选 D3D11，D3D12 保留为实验后端。

这仍不是完整的 D3D11 GPU 纹理零拷贝实现。当前版本继续使用 CPU RGB 转换，自动化测试通过不代表双机游戏串流稳定。下载 Windows 预览包并手动测试实际连接、画面和输入。
