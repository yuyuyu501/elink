# Elink 0.4.21 Windows Preview

画质设置改为独立的串流参数，不再修改被控电脑的系统显示设置。

- 分辨率控制采集后的缩放、编码和接收画面像素尺寸，提供 720p、900p、1080p、1440p 和 4K。设置会保存并用于重连；本机窗口继续等比例适配画面。
- 删除系统缩放倍率选项及 Windows 分辨率/DPI 修改代码；目标帧率只控制串流，不改变物理显示器刷新率。
- 移除原有显示模式变更与恢复流程，旧显示修改接口明确返回停用提示。
- 验证 H.264 Level 5.2 分辨率与帧率预算，超限组合在断开连接前提示；4K 可选最高 60 FPS、1440p 最高 144 FPS。这是配置范围，不是帧率保证。
- 加固剪贴板桥接：读写事务串行执行，读取长度限制在 Windows 实际分配的内存范围内，减少同进程双端轮询的并发风险。
- 更新使用说明，新增云游戏、低延迟视频和拥塞控制论文参考及后续优化顺序。

自动化检查覆盖采集缩放、真实本机 WebRTC 传输像素尺寸、画质应用/取消、配置保存、旧接口停用和参数限制。打包流程还会运行 EXE 音视频自测及自动更新替换验证。

建议两端同时升级以使用 1440p/4K；旧被控端仍限制在 1080p。当前预设为 16:9，非 16:9 桌面会缩放到所选尺寸；高分辨率增加转换、编码和传输开销。仍使用当前 H.264 和 BGR/QImage 显示路径，论文建议的 GPU 呈现与拥塞控制优化尚未实现。真实游戏和双机体验等待用户手动验收；Windows 预览包未签名。
