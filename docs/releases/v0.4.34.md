# Elink 0.4.34 Windows Preview

- 导出性能报告后的“性能报告已保存”提示在 3 秒后自动消失，避免持续遮挡远程画面。
- 新提示会取消上一条提示的关闭计时，避免保存成功的旧计时器误关掉随后出现的错误信息。实际错误继续保留，便于排查。

验证：报告文件写入、提示显示及 3 秒后隐藏、后续错误保留均通过 Qt 自动化测试，并在 Windows 原生窗口复核。完整测试及打包后的音视频、GPU 显示、升级自检由发布流程执行。D3D11 采集回退问题仍待定位，本版本不包含该问题的修复。

Windows x64 便携预览版，解压完整目录后运行 Elink.exe。应用未签名，不安装驱动；双机实际使用仍需人工验收。
