# Elink 0.4.4 Windows Preview

首页改为自动发现的设备列表，点击设备即可连接。采用浅色蓝白界面、设备卡片和串流控制菜单；不再在首页显示参数表单与常驻日志。

## 设备与连接

- 本机状态直接展示在设备页，被控制时显示当前控制端与断开按钮；移除独立的“本机被控”页。
- 局域网与 Tailscale 的同一台设备继续合并显示，保留“通过地址连接”作为发现失败时的入口。
- 连接期间禁用重复连接，失败后恢复操作并保留具体原因与重试建议。网络诊断中的详细记录默认收起。
- 默认串流偏好放在“设置”，监听端口和本机手柄后端放在“高级设置”。已有配置继续使用。

## 串流控制中心

画面上方新增“控制中心”，F8 可打开菜单并释放远端输入。

- 即时切换桌面 / 游戏鼠标模式、手柄转发、本机静音、连接统计和全屏。
- 分辨率、目标帧率、码率、解码器和声音传输可在会话中调整；点击“应用并重新连接”后短暂断开并自动重连，同时保存为默认偏好。取消不改变配置。
- 调整画质重连时保留窗口位置、全屏、静音和统计显示状态。
- 打开菜单或设置时释放远端按键和手柄状态，避免操作本地菜单时继续控制远端。
- F10 显示 / 隐藏统计，F11 全屏；Ctrl+Alt+Shift+Z 释放输入，Ctrl+Alt+Shift+Q 断开。点击画面恢复控制。

本次保留 Windows 系统标题栏与窗口管理，重做应用内部样式与串流工具栏。菜单仅包含已实现能力，不包含 HDR、多显示器切换、麦克风或系统快捷键拦截。画质调整目前通过重连实现，不是无缝切换。

## 下载与验证

下载 **Elink-0.4.4-windows-x64.zip**，完整解压后运行 `Elink/Elink.exe`。已有 0.4.1 或更高版本可在“关于 → 检测更新”升级（开启包括预览版本）。

自动验证覆盖设备点击、防重复连接、失败提示、控制菜单输入释放、取消设置、实际音视频会话重连、本机静音，以及 Windows EXE 与更新替换。实际结果见附带的验证报告。用户安装后的双机手动验收待完成；应用仍为未签名预览版，本次界面更新不代表高帧率游戏或手柄兼容性已完成验收。
