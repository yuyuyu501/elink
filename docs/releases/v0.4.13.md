# Elink 0.4.13 Windows Preview

本版本改进远控输入、状态诊断和应用内更新体验。

- 远控捕获期间拦截 Windows 键和 Alt+Tab，并将按键转发到被控端，释放输入后恢复本机快捷键。
- 修正主键盘方向键与小键盘数字、NumLock 状态之间的映射，避免小键盘 2/4/6/8 被误识别。
- 状态栏重新显示当前解码器名称，例如 D3D11VA 或软件 H.264。
- 关于页面下载更新时显示当前下载速度。
- 使用主控端鼠标模式时隐藏本机系统光标，避免与远程画面中的游戏光标重复显示。
- 保留现有传输分辨率和播放器缩放逻辑；1440p 被控端超过当前 1080p 传输上限时仍会先缩小，以控制编码和网络开销。

自动化测试通过不代表双机游戏串流、系统快捷键拦截或不同游戏光标表现稳定，仍需用户安装后手动验收。当前 Windows 预览包未签名。
