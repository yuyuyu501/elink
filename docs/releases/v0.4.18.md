# Elink 0.4.18 Windows Preview

本版本补充编解码器可观测性，并减少主控端重复的图像转换和绘制开销。

- 状态栏分别显示被控端实际编码器（`h264_nvenc`、`h264_amf`、`h264_qsv` 或 `libx264`）和主控端实际解码器（`D3D11VA` 或软件 H.264）。设置页面仍使用 H.264 这一格式名称。
- 软件 H.264 编码和软件解码线程数调整为 4；硬件编码器和 D3D11VA 会继续由显卡视频引擎自行调度。
- 接收端使用 BGR888 直接包装为 QImage，避免额外的 RGB 通道转换；缓存缩放后的图像，避免在没有新帧时重复进行 Qt 缩放绘制。

自动化测试通过（124 项）。本版本仍需在安装后的真实 Windows 双端环境中手动验收硬件编码器、硬件解码器、实际帧率和画质；当前 Windows 预览包未签名。
