# Elink 0.4.36 Windows Preview

修复窗口化远控时鼠标移出后必须再次点击才能恢复控制的问题，并改进控制中心关闭行为。本版还修复了可复现的灰色桌面导致 D3D11 永久回退问题，保留对原先未知采集故障的诊断。

- 从远控画面边缘移出时释放输入，移回可见画面时自动恢复，无需点击。支持从本机其它窗口返回；被其它窗口、控制中心、标题栏或缩放边框遮挡时不会穿透恢复。主动释放输入仍然有效。
- 点击控制中心及鼠标子菜单之外可关闭面板。关闭面板的点击不会同时点击远端桌面；原有控制中心按钮和 F8 仍可关闭。
- 颜色不足或校准结果暂时有歧义时继续 D3D11 采集，临时使用 CPU 颜色转换并重试校准。出现足够颜色后，同一会话恢复 GPU 转换，不再因灰色桌面一直使用兼容采集。临时转换会有额外开销，性能报告以 `ddagrab-cpu-color` / `capture_calibration=pending` 标明。
- 文件日志先直接写入启动版本，再记录环境；Windows 环境记录改用本地系统版本 API，避免 Python 平台查询可能等待 WMI 的风险。实际异常仍保留消息、堆栈和失败阶段。

验证：Windows 原生 CPU/GPU 窗口覆盖两种窗口尺寸、三种鼠标模式、四个边界、光标显隐、Raw Input 回退、本机窗口切换、遮挡和菜单外点击。真实 D3D11 截取合成灰色区域后恢复 GPU 转换，颜色最大误差为 2/255；取样排除任务栏，不保存桌面像素。另用不支持的奇数尺寸触发真实 D3D11 资源创建失败，验证文件日志、导出报告和兼容采集继续输出；该失败检查也加入打包 EXE 自检。重复初始化主题改为复用现有 Qt 样式，消除完整测试中反复重建样式的崩溃触发点。

日志位置：`%LOCALAPPDATA%\Elink\logs\elink.log`，或“关于 → 打开日志目录”。设置 `ELINK_DATA_DIR` 时在该数据目录下的 `logs` 内。排查被控端采集失败时，应取被控端日志。

此前那次未知 D3D11 失败仍需新版日志确认，不能把灰色画面的受控复现当成原始故障根因已经查明。本版包含已验证的鼠标与校准恢复修复，也作为该未知故障的诊断 Preview。双机游戏和实际驱动兼容性仍待手动验收；应用未签名，不安装驱动。
