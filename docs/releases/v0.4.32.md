# Elink 0.4.32 Windows Preview

- 统一设备页、设置页、关于页和远控控制中心的配色、图标、间距与控件样式。
- 鼠标设置改为控制中心旁的二级面板；灵敏度改用水平滑条，范围 -5.0 至 +5.0、步长 0.1，并提供恢复默认按钮。选择设置后控制中心保持展开。
- 画质标签简化为“分辨率”“帧率”“码率(Mbps)”；下拉列表在输入框下方展开，样式与应用保持一致。
- 连接统计移除开头的 Tailscale 字样，保留 UDP P2P、DERP 中继等实际路径信息。
- 修复窗口化游戏鼠标被强制锁定的问题：三种鼠标模式均可从实际视频边界移出，越界立即停止远端输入并恢复本机指针。窗口化不再自动回中，原始输入及其回退路径均检查边界，缩放窗口使用分数坐标判断，避免提前释放或窗口内外同时响应。仅全屏游戏相对移动保留指针约束，F8 和失焦均可释放。

验证：314 项完整自动化测试通过。Windows 原生 CPU/GPU 检查覆盖 100% 和 150% 缩放、640×400 与 1000×650 窗口、16:9 与 4:3 画面、三种鼠标模式和原始输入回退，共 44 组组合、176 次边界移出，并验证全屏约束、F8、失焦及窗口部分移出屏幕。自动化使用合成窗口和记录输入，不代替双机实际游戏、多显示器或所有驱动组合的人工验收。

Windows x64 便携预览版，需解压完整目录后运行 Elink.exe。鼠标边界修复在控制端生效。应用未签名，不安装驱动。
