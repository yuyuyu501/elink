# Elink 0.4.33 Windows Preview

- 默认灵敏度 0.0 以主控端的 Windows 光标位置为准，按实际视频区域映射；可见桌面光标的三种模式均不叠加被控端鼠标速度与加速，也不受串流分辨率或窗口缩放造成的位移倍率影响。
- 修复大幅移动时本机指针已经移出窗口、远端指针还停在画面内的问题：快速越界及轮询先检测到越界时，先将远端定位到对应边缘，再释放输入。
- 进入桌面控制和游戏退出到桌面时立即对齐位置，点击前也同步定位。关键位置通过可靠控制通道发送，保证先定位再点击或释放，避免运动通道的丢包、乱序及跨通道竞争留下错误位置。
- 保留游戏隐藏光标时的原始相对输入、-5.0 至 +5.0 灵敏度调节，以及窗口化移出边界后释放、全屏相对移动约束和 F8 释放行为。游戏内自己的灵敏度仍然有效，旧主机无法报告光标状态时保留被控端模式的兼容回退。

验证：334 项完整自动化测试通过，包含真实本机 WebRTC 上的位置同步与释放顺序检查；旧边界逻辑在新增的 6 项快速越界回归中均失败，修复后通过。CPU/GPU 原生窗口在 100% 和 150% 缩放下验证 52 组组合、208 次边界移出，另覆盖全屏、F8、失焦及窗口部分移出屏幕。检查使用合成画面和记录输入，不替代双机实际游戏、所有游戏自绘光标或不同驱动组合的人工验收。

本修复在控制端生效，无需更改任一电脑的系统鼠标设置。Windows x64 便携预览版，需解压完整目录后运行 Elink.exe；应用未签名，不安装驱动。
