# Elink 0.5.3 Windows Preview

新增 Windows 常规设置“以管理员身份启动”。开启后，Elink 会在每次启动时
通过标准 UAC 请求管理员权限，以便被控端能够向任务管理器等高完整性窗口发送
键鼠输入；取消授权时仍会以普通权限继续运行。

- 设置会保存在用户配置中，不注册后台服务、不安装驱动，也不绕过 UAC。
- 与开机自启动同时开启时，Windows 登录后也会按系统规则显示 UAC 授权提示。
- 关闭选项后，需要完全退出并重新启动 Elink 才会从管理员进程切换回普通权限。

自动验证：完整 pytest 通过。管理员任务管理器和双机输入仍需在 Windows 两端
安装本 Preview 后由用户手动验收。
