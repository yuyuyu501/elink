# Elink 0.5.2 Windows Preview

修复高权限窗口输入被 Windows UIPI 拒绝时，控制会话被输入回调阻塞并在约
15 秒后断开的路径。普通 Elink 保持原有 `SendInput` 控制；检测到同一桌面
上的高完整性前台窗口后，会按需请求一个独立的管理员输入辅助进程。

- 管理员辅助进程使用一次性随机令牌、回环 TCP、客户端 PID 校验和严格的
  键鼠事件白名单，只接收已验证的输入事件。
- UAC 请求和辅助进程通信放到有界后台队列，不阻塞 RTC 输入回调；UAC 取消、
  超时或辅助进程断开会写入两端日志并提示用户，已按下的键和鼠标按钮会尝试
  释放。
- 新增独立的 `input-broker-*.log` 诊断日志；普通应用日志继续写入
  `%LOCALAPPDATA%\\Elink\\logs\\elink.log`。
- 本地代理启用 TCP_NODELAY，减少高频鼠标事件在回环连接上的等待。

自动验证：完整 pytest 通过，包含权限上下文记录、代理协议白名单、ShellExecuteEx
参数、UAC 非阻塞队列和取消处理测试。管理员任务管理器的真实双机验收仍需在
Windows 两端安装本版本后由用户确认 UAC；本 Preview 不安装驱动、不修改系统
安全策略，不能把自动测试当作真实游戏或跨机性能验收。
