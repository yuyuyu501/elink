# Elink 0.4.17 Windows Preview

本版本针对游戏帧率、丢包、鼠标延迟和 H.264 画质进行了传输链路调整。

- 被控端使用 DXCam 持续采集，编码线程读取最新画面，减少采集和编码互相阻塞造成的帧率抖动。
- 在 RTP 发送层按用户码率平滑发送视频包，避免单帧数据突发压垮 Wi-Fi 或 Tailscale 队列；固定优先策略仍保持用户设置的编码目标，不会因为静态画面的 REMB 估计自动压低码率。
- H.264 改用 High profile/CABAC，在相同码率下改善游戏细节、文字和植被的块状毛糙；编码器仍保持无 B 帧低延迟配置。
- 游戏相对鼠标改用 Windows Raw Input，使用主控端设备的原始移动量，绕过主控端系统加速度和 Qt 鼠标事件合并；Raw Input 不可用时保留 Qt 回退路径。
- RTP pacing 与 DXCam 采集均保留旧版本兼容回退，未加入 FSR 超分。FSR 不能恢复 H.264 已丢失的细节，且 540p 传输会损失文字和桌面 UI；后续 GPU 纹理渲染阶段再评估超分或锐化。

自动化测试通过（124 项）。本地双端合成串流测试约 29–30 FPS、视频丢包 0；真实 Tailscale 链路、不同游戏的 Raw Input 行为和画质仍需安装后手动验收。当前 Windows 预览包未签名。
