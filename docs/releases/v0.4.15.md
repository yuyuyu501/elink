# Elink 0.4.15 Windows Preview

本版本更新远控输入和被控端显示同步体验。

- Tab 键在远控捕获后直接转发到被控端，移除画面左下角操作提示，避免与游戏按键和画面内容冲突。
- “使用主控端鼠标”会根据被控端系统光标状态自动切换：桌面显示主控端软件光标，游戏隐藏被控端光标时隐藏软件箭头并使用相对鼠标输入。
- 远控画质设置中的目标帧率改为被控端显示刷新率。应用显示模式时同步设置分辨率和刷新率，串流帧率跟随该刷新率，并在断开时恢复进入远控前的显示设置。
- 保留被控端分辨率与系统缩放设置，刷新率列表会随选定分辨率更新。

自动化测试通过（123 项）。Windows 双机游戏串流、不同游戏的光标隐藏行为、显示刷新率切换和退出恢复仍需安装后手动验收。当前 Windows 预览包未签名。
