# 串流状态浮层

默认显示在画面左上角，白字、半透明背景、紧凑纵向排布。F10 显示 / 隐藏，F11 全屏。未捕获输入时底部提示如何进入控制；捕获后隐藏底部提示，减少遮挡。

| 字段 | 含义 |
| --- | --- |
| UDP / Tailscale 路径 | 读取当前 ICE 实际选中的路径。Tailscale 额外每约 15 秒探测一次，结果 35 秒后过期；未查明时显示路径待测，不冒充 P2P |
| fps | 最近一秒界面实际绘制的新视频帧数，不把重复重绘算作新帧；不代表显示器扫描输出帧率 |
| Mbps | WebRTC 传输接收字节计数的每秒增量 × 8 / 1,000,000，保留一位小数。包含音视频、控制和加密开销，不是纯视频编码码率，也不是网络最大带宽 |
| ms RTT | 控制通道 ping / pong 往返时间，超过 3 秒没有更新时显示未知 |
| ms / frame | 1000 / 实际绘制 FPS；没有新帧时显示未知，不代表编码耗时或端到端延迟 |
| % loss | 最近统计间隔中视频 RTP 丢失增量 /（接收增量 + 丢失增量）；迟到包导致累计丢包下降时不显示负值，无新包则显示未知 |

统计约每秒采样一次。计数按本次接收会话重置，共享音视频传输只累计一次。统计失败不会中断串流；超过 3 秒没有新样本时数值显示 `--`。六行之外不再显示连接时长、码率上限、抖动、解码耗时或解码器。内部诊断仍保留抖动和解码采样，码率上限仍可在画质设置中调整。

两个毫秒指标分别为网络往返 RTT 和根据 FPS 计算的帧间隔，不能相加视作总延迟；当前不提供未经测量的端到端游戏延迟。
