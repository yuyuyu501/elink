# Elink 0.6.3

## 更新内容

- 启动后自动发现设备并监听连接，移除允许设备发现和手动开放桌面的开关。
- 点击设备后自动协商并开始传输，断开后释放媒体和输入资源，继续等待连接。
- 在会话内切换观看与远控模式，无需重新建立画面连接。
- 在连接后调整分辨率、帧率和码率；码率使用 Mbps，参数生效后保存，失败时恢复此前参数。
- 修正 SRT 收发方向、管线重建时的状态判断，以及重复连接时的线程和资源清理。

## 安装

- Windows 10/11 x64，解压便携 ZIP 后打开 `Elink/Elink.exe`，或运行 Setup 安装包。
- 运行时需要 PATH 中存在 `ffmpeg`。
- 保留 `%LOCALAPPDATA%\Elink` 下的用户配置；连接双方均需使用支持本次会话协议的版本。
