# Elink 0.6.0

这是新 Elink 桌面端的首个完整发布包，用来替换旧版 `elink 0.5.x`：

- 安装包使用与旧版相同的 AppId、默认目录 `%LOCALAPPDATA%\Programs\Elink` 和
  用户配置目录 `%LOCALAPPDATA%\Elink`；安装新版会覆盖旧程序文件，配置保留。
- 便携包解压后请保留整个 `Elink/` 目录。

## 本次包含

- 新的桌面界面（总览 / 主机 / 观看 / 设备与发现 / 日志 / 设置）。
- 同局域网 UDP 发现设备，点击即可填入 SRT + 控制地址。
- 文本剪贴板双向同步（Windows，最多 64000 字符）。
- XInput 手柄转发与 ViGEmBus 虚拟 Xbox 360 手柄注入（需要另装 ViGEmBus 驱动）。
- 独立全屏播放器：F8 释放输入、F10 统计叠加、F11 进入/退出全屏。
- 观看端超分辨率：FSR 1（EASU + RCAS）与 RTX VSR（NVIDIA D3D11），1080p/1440p/4K 输出。
- 性能报告导出：编码 / 解码 / 渲染耗时的 P50 / P95 / P99。
- 托盘、关闭到托盘、开机自启、启动后自动开启主机。
- 错误/警告提示条、诊断信息复制、日志目录入口。

## 安装

- Windows 10/11 x64。
- 运行 `Elink-0.6.0-windows-x64-setup.exe`，或解压便携 ZIP 后双击 `Elink.exe`。
- 运行时需要 PATH 中存在 `ffmpeg`（建议带 libx264 / libsrt）。
- 手柄注入还需要系统安装 ViGEmBus 驱动；未安装时手柄开关会提示不可用，键鼠与串流不受影响。

## 已知限制

- 安装包尚未代码签名，SmartScreen 可能提示。
- 发现服务是无鉴权 UDP 广播，仅适合个人局域网；需要防火墙放行 UDP 49320。
- 性能报告只覆盖本机管线的编码/解码/渲染阶段，不是端到端网络延迟。
- 超分的 RTX VSR 需要 NVIDIA RTX 显卡和较新驱动，其它显卡自动回退 FSR 1；
  两种模式都会回读 CPU，4K 输出下帧率可能低于 30fps。
- 不包含旧版的 WebRTC/公网信令，跨公网请使用可达地址或外部组网工具。

## 校验

`SHA256SUMS.txt` 包含便携 ZIP 与安装包的 SHA-256；`verification.json` 记录构建时间、
自检结果和产物摘要。
