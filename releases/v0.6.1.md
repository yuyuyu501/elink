# Elink 0.6.1

## 更新内容

- 默认进入设备列表，点击设备打开详情；左上角返回列表，右上角显示设备状态与信息。
- 设备详情提供“进入桌面”和“观看模式”；观看模式关闭键鼠、剪贴板及手柄转发。
- 自动枚举物理及虚拟网卡，通过支持广播的 IPv4 接口发现运行 Elink 的设备，无需手动刷新。
- 同一设备的多个地址合并显示，自动处理地址过期，连接前重新读取有效地址。
- 移除独立日志页面，保留诊断信息复制。
- 码率统一显示为“码率（Mbps）”，输入框只显示数值。

## 安装

- Windows 10/11 x64，运行安装包，或完整解压便携 ZIP 后打开 `Elink/Elink.exe`。
- 安装新版保留原有用户配置。
- 运行时需要 PATH 中存在 `ffmpeg`；手柄注入需要 ViGEmBus 驱动。

## 当前限制

- 自动发现需要发现消息能到达对方，双方均需运行兼容的 Elink 并开启设备发现。
- 连接前，对方仍需通过“高级连接 → 主机配置”开放 SRT 串流。
- 文件传输、终端与端口映射暂未开放。
- 安装包尚未代码签名。

`SHA256SUMS.txt` 提供下载校验，`verification.json` 记录构建与自检结果。
